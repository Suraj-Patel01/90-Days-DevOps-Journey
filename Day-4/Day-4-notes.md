# Day 04 – Linux Practice: Processes and Services

## Objective

Today's goal was to practice Linux fundamentals using real commands and understand how to check processes, services, and logs during troubleshooting.

---

# Process Checks

## 1. Check Running Processes

```bash
ps aux
```

### Observation

Displayed all running processes along with their users, PIDs, CPU usage, memory usage, and commands.

---

## 2. Monitor Processes

```bash
top
```

### Observation

Displayed real-time CPU, memory, load, and running process information.

---

## 3. Find a Specific Process

```bash
pgrep ssh
```

### Observation

Displayed the PID of the matching SSH process if it was running.

---

# Service Checks

For practice, I inspected the **SSH service**.

## 1. Check SSH Service Status

```bash
systemctl status ssh
```

### Observation

Displayed whether the SSH service was active, inactive, or failed.

---

## 2. Check SSH Service State

```bash
systemctl is-active ssh
```

### Observation

Returned the current state of the SSH service. A healthy running service should return:

```text
active
```

---

## 3. List Running Services

```bash
systemctl list-units --type=service --state=running
```

### Observation

Displayed the system services that are currently running.

---

# Log Checks

## 1. Check SSH Logs

```bash
journalctl -u ssh
```

### Observation

Displayed logs generated by the SSH service, which can help identify errors or connection problems.

---

## 2. View Recent SSH Logs

```bash
journalctl -u ssh -n 50
```

### Observation

Displayed the latest 50 log entries for the SSH service.

---

# Mini Troubleshooting Flow

If the SSH service is not working, I would follow these steps:

### Step 1 – Check Service Status

```bash
systemctl status ssh
```

### Step 2 – Check Recent Logs

```bash
journalctl -u ssh -n 50
```

### Step 3 – Check SSH Process

```bash
pgrep sshd
```

### Step 4 – Check Listening Port

```bash
ss -tulpn | grep :22
```

### Step 5 – Restart if Required

```bash
sudo systemctl restart ssh
```

### Step 6 – Verify Again

```bash
systemctl is-active ssh
```

* A service is not starting.
